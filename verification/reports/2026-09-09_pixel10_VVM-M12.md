## Implemented scope

- MapLibre Native is integrated and initialized inside an Android presentation
  adapter before its map view is created;
- OpenFreeMap is configured only through the provider's Liberty style URI, outside
  domain and analysis-state code;
- full route, selected range, endpoints, and selected position are independent
  local GeoJSON sources/layers above the basemap;
- retained route segments are rendered as separate line features, and known gaps
  are never connected;
- a pure JVM route lookup maps a touch-near-route candidate to the closest valid
  point and interpolated canonical active elapsed time within a single segment;
- a 48 dp screen tolerance is converted to metres at the touched map latitude;
- graph selection updates the MapLibre marker through the M11 canonical state;
- map selection updates the shared graph cursors, inspector, and canonical state;
- range changes update a separately emphasized, segment-preserving route layer;
- touch pan/zoom does not change selection, graph interaction does not recenter
  the viewport, and a Full route action explicitly restores route framing;
- connectivity loss switches to a local blank style while retaining route layers,
  graphs, selection, and inspection, with an explicit basemap-unavailable state;
- style-request generations prevent stale asynchronous provider callbacks from
  overwriting a newer online/offline style decision.

## Privacy request review

RADM passes only this constant to the provider:

```text
https://tiles.openfreemap.org/styles/liberty
```

The URI has no query or fragment. Activity UUID, title, notes, pace, cadence, and
step data are not inputs to the provider configuration or MapLibre tile/style
request path. Requested tile coordinates necessarily disclose the viewed area, as
permitted by `SRS-PRIV-005` and `VVM-PRIV-001`.
