## Implemented scope

- a persistence-neutral `ActivityAnalysisData` loader reads metadata, current
  summary, route segments, source elevation, current distance/pace/speed/cadence,
  and processor validity into one in-memory dataset;
- stale, failed, or unprocessed derived streams are not exposed as current while
  retained source and persisted derived rows remain unchanged;
- analysis initializes to the full activity range, the start logical position,
  and Distance coordinate mode when distance is meaningful;
- activities without distance use Active Elapsed Time so locally available
  cadence and metadata remain usable;
- route and step discontinuities are retained as distinct chart continuity
  groups, and distance is not interpolated across a route boundary;
- Activity Analysis presents its header, local route-data status, type-specific
  pace or speed, source elevation, Running cadence, and initial point inspector;
- static metric graphs use Vico 2.3.3 and operate from the loaded in-memory data;
- a missing route, elevation value set, cadence stream, or non-current derived
  stream is represented locally without collapsing unrelated sections;
- editing and protected deletion remain available from the analysis screen.

Static MapLibre presentation is optional in M10 and was not introduced. Map
rendering and synchronized map interaction remain assigned to M12.

## Specification interpretation

`RADM-UX_R00.md` `UXM-COORD-002` and `UXM-INIT-002` state that Distance
is the initial/default coordinate without qualification. `RADM-PRD_R00.md`
sections 42 and 44 qualify Distance as the default "where meaningful."

An activity with no route has no distance coordinate, while `VVM-AN-011`
requires its remaining analysis to stay usable. M10 therefore uses Distance when
a current distance series exists and Active Elapsed Time otherwise. Active
elapsed time remains the authoritative logical coordinate in both cases.
